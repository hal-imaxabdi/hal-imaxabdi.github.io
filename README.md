# Halima — Portfolio (React + Framer Motion)

## View it
Open `site/index.html` (double-click). Everything is bundled, fonts included, no server needed.

## Deploy (Vercel / Netlify / GitHub Pages)
Upload the contents of the `site/` folder. That's the whole website.

## Edit your content
All text, projects, jobs, skills and certificates live in `src/data.js`.
After editing, rebuild once:

    npm install
    npm run build

This regenerates `site/app.js`. Layout lives in `src/main.jsx`, styling in `site/style.css`.

## Swap images
Project screenshots: `site/assets/img/`. Certificate images: `site/assets/certs/` (names listed in `src/data.js`). Video: `site/assets/hero.mp4`.
