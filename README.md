# hal-imaxabdi.github.io

Personal portfolio for Halima Abdirizak Mohamed: software engineering and application security.
Plain HTML, CSS and JavaScript, based on Bedimcode's "Responsive Portfolio Website" tutorial.

- Edit projects and certificates in `assets/js/main.js` (the `projects` and `certs` arrays).
- Change the theme colour with `--hue` in `assets/css/styles.css` (215 = blue).
- Contact form: add your EmailJS IDs in `assets/js/main.js` (see the comment there). Until then it opens the visitor's email app.
- Deploys automatically to GitHub Pages on every push to `main` (`.github/workflows/deploy.yml`, no build step).
